# Sources

[中文](SOURCES.zh-CN.md)

**All source data and modeling references used by PKU-3D come from publicly available sources.** The scene also includes approximate modeling decisions and spatial corrections made during development. Public access to a source does not make it public domain.

| Source | Use | Rights |
| --- | --- | --- |
| [OpenStreetMap](https://www.openstreetmap.org/copyright) | Building footprints, roads, water and place records | © OpenStreetMap contributors; [ODbL 1.0](../DATA_LICENSE.md) |
| [Esri World Imagery](https://www.arcgis.com/home/item.html?id=10df2279f9684e4a9f6a7f08febac2a9) | Aerial reference for layout and roof outlines | Esri and imagery providers; separate service and content terms apply |
| [Public university information](https://www.pku.edu.cn/visit.html), department websites and architectural publications | Building names, appearance and spatial checks | Rights remain with the respective authors and publishers |
| Project-generated materials | Procedural surface textures, signs, interface graphics and scene renders | Original project work; see [Licensing notes](LICENSING.md) |

Reference photographs, videos and research collections remain outside the source repository and release package. README images are renders of this project, not copies of reference photographs. No university crest is used in the interface.

Some heights, dimensions, concealed elevations and fine details are approximations. The scene is not a surveyed building model. For corrections, include a building name, marked screenshot and public source link in an [issue](https://github.com/sldyns/PKU-3D/issues/new/choose).

The published website links to satellite and standard maps on provider websites. Downloaded map mosaics are excluded from the source repository and release assets.
