# 数据来源

[English](SOURCES.md)

**PKU-3D 使用的全部基础数据与建模参考均来自公开来源。** 场景也包含开发中的近似建模与空间校对。公开可访问不等于属于公有领域。

| 来源 | 用途 | 权利说明 |
| --- | --- | --- |
| [OpenStreetMap](https://www.openstreetmap.org/copyright) | 建筑占地、道路、水系与地点信息 | © OpenStreetMap 贡献者；[ODbL 1.0](../DATA_LICENSE.md) |
| [Esri World Imagery](https://www.arcgis.com/home/item.html?id=10df2279f9684e4a9f6a7f08febac2a9) | 布局与屋顶轮廓的影像参考 | Esri 及影像提供方所有，受各自服务与内容条款约束 |
| [学校公开信息](https://www.pku.edu.cn/visit.html)、院系网站与建筑出版资料 | 核对楼名、外观及空间关系 | 权利归相应作者与出版方所有 |
| 项目生成素材 | 程序生成的表面纹理、标牌、界面图形与场景截图 | 项目原创内容，见[许可说明](LICENSING.md) |

参考照片、视频和研究资料不进入源码仓库或发布包。README 图片来自本项目渲染，没有直接使用参考照片。界面不使用北大校徽。

部分高度、尺寸、遮挡立面与细节为近似；场景不是实测建筑模型。反馈时请在 [Issue](https://github.com/sldyns/PKU-3D/issues/new/choose) 中附上楼名、圈注截图和公开来源链接。

发布网页通过链接在提供方官网查看卫星图与标准地图；下载的地图拼图不进入源码仓库或发布包。
